# Що відкривати і як користуватися

Це відновлений Python-проєкт для BU7141. Він рахує результати з сирого Excel,
зіставляє їх із наданими результатами команди та створює справжню SQLite-базу
за оновленою ERD із чотирьох таблиць.

**Оригінальні ноутбуки Їнрана не були надані.** Це новий код, який відтворює
перевірені результати його аналізу. У рапорті та GitHub ці дві речі треба
розрізняти.

1. Розпакуй весь архів.
2. У VS Code відкрий папку `sports_centre_reconstruction`.
3. Відкрий Terminal та виконай:

```bash
python -m pip install -r requirements.txt
python run.py
```

Якщо у Windows команда `python` не працює, спробуй `py` замість неї.
Для ноутбука відкрий `Start_here.ipynb` і запускай клітинки по черзі.

## Готові файли

- `outputs/database/sports_centre.sqlite` — готова база. Її можна відкрити через
  Python або програму перегляду SQLite.
- `outputs/data/AnalysisData.csv` — відновлена аналітична таблиця, 14 942 клієнти.
- `outputs/monthly/AnnualSummary.csv` — річні підсумки для рапорту.
- `outputs/age_groups/SeasonalComparison.csv` — сезонні порівняння вікових груп.
- `outputs/retention/Summary.csv` — результати утримання. Для основного
  порівняння обирай `Scope = All 2015-2018` і окремо 90 або 180 днів.
- `outputs/descriptive/` — активності, гендер/вік, renewals і середні показники
  використання, пораховані з сирих даних.
- `outputs/VALIDATION.md` — які частини Excel перевірено і чи є розбіжності.
- `METHODS.md` — точні визначення та формули для пояснення методології.

CSV можна відкрити в Excel або підключити до Tableau. Вихідні Excel-файли
команди залишилися незміненими у `reference/`.

## Для рапорту

Тепер можна показати шлях «сирі дані → підготовлена таблиця → розраховані
показники → перевірка проти Excel → чотири таблиці SQLite» з виконуваним кодом.
Створення SQLite-бази — доданий на цьому етапі крок. Не треба писати, що команда
вже використовувала цю базу для попередніх Python/Tableau-результатів.

Цей пакет сам нічого не публікує на GitHub. Код і документація готові для
завантаження до погодженого репозиторію та коректного опису авторства.
